01 / THE ORIGINALWINDOWS, 1997

Before fast internet,
there was GetRight.

A dropped connection didn't have to mean starting over.

Michael Burford released GetRight 1.0 in February 1997. His idea grew out of a familiar frustration: a game demo download that kept getting disconnected.

GetRight became a familiar name on Windows desktops, helping people resume and organize downloads in the dial-up era. The green progress bars, the tray icon, the feeling of finally reaching 100% — that's the part we wanted to bring along.

02 / THROUGH THE TIME TUNNEL

Nostalgia is the spark.
Code is the time machine.

This is an independent porting and software archaeology project by Jorge Pereira. Reverse engineering (REV), REA — the Reverse Engineering Assistant — and OpenAI Codex help turn observed behavior into readable C++17 and Qt 6 code.

We are rebuilding the experience, not recovering the original source byte for byte. The project starts with macOS on Apple Silicon, bringing a piece of 1990s software culture into a modern, open source codebase.

Installation & building from source +

Open the DMG and copy the app to Applications, or extract the application ZIP. Release bundles include Qt. The app is ad-hoc signed and is not Apple-notarized.

To build the source on a Mac:

brew install cmake qt
git clone https://github.com/jpereira/getright.git
cd getright
make osx
